# Verkefni 3 – Viðskiptamarkmið, sýn og umfang

**Kerfi:** Cafeteria Ordering System (COS)  
**Höfundur:** Ebba Þóra Hvannberg, hópur 0

Þessi geymsla inniheldur drög að sýnislausn fyrir verkefni 3 í HBV301G Verkfræði kröfugreiningar 2026. Lausnin fjallar um viðskiptamarkmið, framtíðarsýn og fyrstu nothæfu útgáfu mötuneytispöntunarkerfisins COS og byggir á COS-greiningu fyrri verkefna.

- [VISION-MVP.md](VISION-MVP.md): Mælanleg viðskiptamarkmið, framtíðarsýn, prófílar lykilhagsmunaaðila, forgangsröðun og umfang MVP.
- [REKJANLEIKI.md](REKJANLEIKI.md): Uppruni efnis, aðlaganir og tillögur Codex sem þarf að rýna sérstaklega.
- [Vinnuferli.md](Vinnuferli.md): Sniðmát fyrir verkaskiptingu, ígrundun og gagnsæisyfirlýsingu. Það á eftir að fylla út samkvæmt raunverulegu vinnuferli.

Til stuðnings við lestur og rýni lausnarinnar:

- [Verkefnislýsing](Heimildir/Verkefni%203%20Viðskiptamarkmið,%20sýn%20og%20umfang.html): Efnisatriði og kröfur verkefnis 3.
- [Matskvarði](Verkefni3-matskvarði.pdf): Matsviðmið verkefnisins.
- [Kennsluefni 6.1](Heimildir/6.1%20Viðskiptamarkmið,%20framtíðarsýn,%20forgangsröðun%20og%20MVP%20_%20HBV301G%20Verkfræði%20kröfugreiningar.pdf): Viðskiptamarkmið, framtíðarsýn, forgangsröðun og MVP.
- [Yfirferð verkefnis 3](Heimildir/9.2%20Yfirferð%20á%20verkefni%203.html): Almenn endurgjöf og atriði sem má bæta í lausnum.

Lausnin byggir á [COS-lausn verkefnis 1](https://github.com/Hvannberg/HBV301G-2026-COS) og [COS-lausn verkefnis 2](https://github.com/Hvannberg/HBV301G-Verkefni2-lausn).

Meginskjalinu hefur verið aðlagað að template-i ársins. Viðmiðunartölur eru merktar og tillögur sem þurfa staðfestingu hagsmunaaðila eru aðgreindar frá fyrirliggjandi upplýsingum. Uppruni efnis og aðlaganir eru skráð í [rekjanleikaskjalinu](REKJANLEIKI.md).
